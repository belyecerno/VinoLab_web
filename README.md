# VinoLab — прогноз качества вина

Веб-приложение (Streamlit), которое по 11 лабораторным показателям предсказывает дегустационную оценку вина,
показывает 90-процентный интервал и объясняет, какие показатели повлияли на прогноз.

* Данные: UCI Wine Quality (6497 проб, Португалия).
* Модель: ансамбль Extra Trees + градиентный бустинг + SVR, честный R² ≈ 0,40 (проверка без дубликатов).
* Кейс 12. Команда: Чирисов Иван, Яблоков Андрей, Калинина Арина, Тюрина Валерия, Курзин Ян.

Запуск локально: `pip install -r requirements.txt` и `streamlit run app.py`.
